# AI-Sidekick-Beta-1.0
Sidekick Beta 1.0 is a Windows desktop assistant with bundled offline AI, customizable appearance, and saved chats.  Requires Windows 10 22H2 or Windows 11, 64-bit, and .NET Framework 4.8.  Extract the entire ZIP and run Sidekick.exe. For installation and startup support, run Sidekick.Setup.exe.  No API key or separate AI download is required.
